## Lecciones
- La API de Supabase devuelve como mucho 1000 filas: listas largas (kardex) se leen por páginas.
- Filtros de fecha en hora de Lima (`-05:00`), no en UTC.
- Al bloquear escrituras con sesión, las pruebas SQL antiguas necesitan una sesión con el módulo, y las de ventas, sacos con stock.
- Un mutante que quita un `ORDER BY` puede sobrevivir porque Postgres devuelve ese orden por casualidad; no basta con cambiar el orden de los ids.
- El control de subida exige una spec aprobada para todo cambio de nivel 2, aunque se haya hecho por FTD.
